# AI_DONE — Completed tasks + incidents

> The autonomous cycle appends each completed task as a **row in the Done table** below (timestamp, ID, group,
> depends, task description, files, evidence — links into `.4pm/evidence/AI_DONE/<ID>/`) and logs incidents as rows in the **Incidents** table — per
> `.claude/templates/AI_DONE.sample.md`.
> **Title** = a short name for the row (plain text, one line, ≤ 80 characters) — the web grid shows it on the row.
